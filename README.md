# Lutli

Lutli is a planned camera app for shooting with live, film-inspired LUT looks. It will include a curated built-in collection and a limited collection of user-imported LUTs.

The working app name is **Lutli**, styled **lutli** in the interface. Development is planned for iOS first, with Android later. The implementation framework is undecided.

## Planning

- [Product plan](docs/planning/product-plan.md): confirmed direction, proposed first-release scope, and open decisions.
- [UI and navigation](docs/planning/ui-ux.md): the current visual baseline, filter-label editor, and saved mockups.
